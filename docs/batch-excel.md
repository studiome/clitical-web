# Excel一括処理

CLiTICALの「一括処理」画面では、複数症例を記載したExcelファイルをブラウザ内で読み込み、既存のリスク予測モデルで一括計算できます。Excelファイルと症例データはサーバーへ送信されません。

## 基本操作

1. ナビゲーションの「一括処理」を開きます。
2. 「Excelテンプレートをダウンロード」を選択します。
3. `Data Entry`シートへ1行に1症例を入力します。
4. 編集した`.xlsx`ファイルを画面で選択します。
5. 読み込んだ症例数を確認し、「計算開始」を選択します。
6. 画面上で成功・エラーと計算結果を確認します。
7. 必要に応じて「計算結果をダウンロード」を選択します。

## テンプレート構成

テンプレートには次の2シートがあります。

- `Data Entry`: 症例入力用。1行目は変更してはいけないフィールド名です。
- `Input Guide`: 各フィールドの日本語・英語名称、許容値、単位を記載しています。

`Data Entry`の1列目には、`CASE-0001`から`CASE-0100`までの仮症例IDがあらかじめ連番で入力されています。これは画面と出力Excelで同じ症例を対応付けるためのIDです。氏名、カルテ番号など、個人を直接特定できる情報へ置き換えないでください。

テンプレートは100行を用意しています。仮症例IDだけが入っている行はアップロード時に無視されます。仮症例IDを空欄にした入力行には、読込順に`CASE-0001`形式のIDが補完されます。

## 入力値

列名はアプリ内の安定したコード値を使用します。選択式のセルはExcelのプルダウンから選択してください。

| 分類   | フィールド                    | 許容値                                 |
| ------ | ----------------------------- | -------------------------------------- |
| 数値   | `age`                         | 1–150の整数                            |
| 数値   | `heightCm`                    | 0より大きく300以下、cm                 |
| 数値   | `weight`                      | 0より大きく1000以下、kg                |
| 数値   | `alb`                         | 0より大きく20以下、g/dL                |
| 選択   | `sex`                         | `male`, `female`                       |
| 選択   | `activity`                    | `ambulatory`, `wheelchair`, `immobile` |
| 選択   | `ckd`                         | `normal`, `g3`, `g4`, `g5`, `g5D`      |
| 選択   | `malignant`                   | `no`, `pastHistory`, `underTreatment`  |
| 選択   | `rutherford`                  | `class4`, `class5`, `class6`           |
| 真偽値 | `has...`, `is...`で始まる各列 | `yes`, `no`                            |

血行再建対象病変の`hasAILesion`、`hasFPLesion`、`hasBKLesion`は、少なくとも1つを`yes`にする必要があります。

## 計算結果

画面には仮症例ID、成功・エラー、GNRI、2年OS、2年AFS、30日死亡・大切断率、30日MALE発生率を表示します。

出力Excelの`Results`シートには、元の入力値を保持したまま、次の情報を追加します。

- 行ごとの`success`または`error`
- フィールド名とエラーコード
- GNRIとGNRIリスク区分
- 予測2年OSとOSリスク区分
- 予測2年AFS
- 予測30日死亡・大切断率
- 予測30日MALE発生率
- 計算に使用したモデルバージョン

一部の行に入力エラーがあっても、正常な行は計算されます。エラー行は入力値を維持したまま画面と出力Excelで示されるため、元のファイルを修正して再度読み込めます。

## セキュリティと運用

- Excelの読込、検証、計算、結果生成はすべてブラウザ内で行います。
- 氏名、生年月日、住所、電話番号、メールアドレス、カルテ番号などの直接識別子を入力しないでください。
- ダウンロードした入力・結果ファイルの保管と削除は、所属施設の情報管理規定に従ってください。
- 本機能は意思決定支援であり、診断や臨床判断を代替するものではありません。

## 開発者向け

Excel処理は`src/app/batch-processing/`にまとまっています。

- `batch-schema.ts`: Excel列と一括入力型
- `batch-calculation.ts`: 型変換、行単位の検証、既存モデルの呼び出し
- `batch-workbook.ts`: テンプレート生成、読込、結果Excel生成
- `batch-processing.ts`: 画面状態と利用者操作

計算係数はExcelへ複製せず、単一症例画面と同じ`calculatePatientRisk()`を呼び出します。計算ロジックを変更するときは、単一症例と一括処理のテストを同時に確認してください。
