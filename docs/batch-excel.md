# Excel一括処理

CLiTICALの「一括処理」画面では、複数症例を記載したExcelファイルをブラウザ内で読み込み、既存のリスク予測モデルで一括計算できます。Excelファイルと症例データはサーバーへ送信されません。

## 基本操作

1. ナビゲーションの「一括処理」を開きます。
2. 「日本語版テンプレート」または「英語版テンプレート」を選択します。
3. 日本語版は`症例入力`、英語版は`Data Entry`シートへ1行に1症例を入力します。
4. 編集した`.xlsx`ファイルを画面で選択します。
5. 読み込んだ症例数を確認し、「計算開始」を選択します。
6. 画面上で成功・エラーと計算結果を確認します。
7. 必要に応じて「計算結果をダウンロード」を選択します。

## テンプレート構成

日本語版と英語版の2種類があり、どちらも次の2シートで構成されます。

- `症例入力` / `Data Entry`: 症例入力用。1行目はWebアプリと同じ設問名です。
- `入力ガイド` / `Input Guide`: 内部フィールドコード、設問名、入力可能な値を記載しています。

症例入力シートの1列目には、`CASE-0001`から`CASE-0100`までの仮症例IDがあらかじめ連番で入力されています。これは画面と出力Excelで同じ症例を対応付けるためのIDです。

テンプレートは100行を用意しています。仮症例IDだけが入っている行はアップロード時に無視されます。仮症例IDを空欄にした入力行には、読込順に`CASE-0001`形式のIDが補完されます。

## 入力値

列名にはWebアプリの設問名と単位表記をそのまま使用します。列名と並び順は変更しないでください。選択式のセルはExcelのプルダウンから選択します。日本語版では日本語、英語版では英語の選択肢が表示され、アップロード時に同じ内部値へ変換されます。

| 分類   | 設問の例                       | 日本語版                        | 英語版                                 |
| ------ | ------------------------------ | ------------------------------- | -------------------------------------- |
| 数値   | 年齢、身長、体重、アルブミン値 | 指定範囲内の数値                | Number in the permitted range          |
| 選択   | 性別                           | `男性`, `女性`                  | `Male`, `Female`                       |
| 選択   | ADL                            | `独歩`, `車いす`, `寝たきり`    | `Ambulatory`, `WheelChair`, `Immobile` |
| 選択   | 慢性腎臓病                     | `正常`, `G3`, `G4`, `G5`, `G5D` | `No`, `G3`, `G4`, `G5`, `G5D`          |
| 選択   | 悪性新生物                     | `なし`, `既往歴あり`, `治療中`  | `No`, `Past History`, `UnderTreatment` |
| 選択   | ラザフォード分類               | `Class 4`, `Class 5`, `Class 6` | 同左                                   |
| 真偽値 | 合併症・病変など               | `あり`, `なし`                  | `Yes`, `No`                            |

血行再建対象病変の「大動脈腸骨動脈領域病変」「大腿膝窩領域病変」「膝下膝窩以下末梢領域病変」は、少なくとも1つを「あり」または`Yes`にする必要があります。

## 計算結果

画面には仮症例ID、成功・エラー、GNRI、2年OS、2年AFS、30日死亡・大切断率、30日MALE発生率を表示します。

出力Excelの`Results`シートには、元の入力値を保持したまま、次の情報を追加します。

- 行ごとの`success`または`error`
- フィールド名とエラーコード
- GNRIとGNRIリスク区分
- 予測2年OSとOSリスク区分
- 予測2年AFS
- 予測30日死亡・大切断率
- 予測30日MALE発生率
- 計算に使用したモデルバージョン

一部の行に入力エラーがあっても、正常な行は計算されます。エラー行は入力値を維持したまま画面と出力Excelで示されるため、元のファイルを修正して再度読み込めます。

## セキュリティと運用

- Excelの読込、検証、計算、結果生成はすべてブラウザ内で行います。
- ダウンロードした入力・結果ファイルの保管と削除は、所属施設の情報管理規定に従ってください。
- 本機能は意思決定支援であり、診断や臨床判断を代替するものではありません。

## 開発者向け

Excel処理は`src/app/batch-processing/`にまとまっています。

- `batch-schema.ts`: Excel列と一括入力型
- `batch-calculation.ts`: 型変換、行単位の検証、既存モデルの呼び出し
- `batch-workbook.ts`: テンプレート生成、読込、結果Excel生成
- `batch-processing.ts`: 画面状態と利用者操作

計算係数はExcelへ複製せず、単一症例画面と同じ`calculatePatientRisk()`を呼び出します。計算ロジックを変更するときは、単一症例と一括処理のテストを同時に確認してください。
